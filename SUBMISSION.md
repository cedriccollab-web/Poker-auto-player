# Submission: Prefer not to say

Team **Prefer not to say** (pickle name `prefer-not-to-say`). The bot is
exactly these two files at the repository root, on branch `main`:

| File | What it is |
|---|---|
| `prefer-not-to-say.pkl` | `pickle.dump(Model())`, built by `python -m submit --team prefer-not-to-say`; it names only `model.Model` and `model.OpponentStats` |
| `model.py` | the whole bot in one self-contained file; `Model.run(actions, game_state)` as on the competition website |

`model.py` imports only `random` and the organisers' `card_utils`,
`game_state` and `player_action`: no other team file, no files, network or
engine internals. The code review flags nothing in it.

To rebuild and check it from a clean clone:

```sh
python -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m submit --team prefer-not-to-say
```

That lists the same two files and plays the model from a clean copy of just
those files against every dummy bot, with no faults.

**Not part of the bot** (development only): `model.py` is generated by
`tools/bundle_model.py` from `strategy.py`, `equity.py`, `opponent.py` and
`preflop_table.py`, which are kept for development and tests. `sparring.py`
and `bots/` are practice opponents, `snapshots/` holds earlier versions used
as test opponents, plus `tests/` and `docs/`. The organisers' files
(`card_utils.py`, `player_action.py`, `game_state.py`, `game_interface.py`,
`engine.py`, `arena/`, `evals/`, `submit.py`) are unchanged from upstream.
